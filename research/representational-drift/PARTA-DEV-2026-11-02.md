## 2. Data route: nothing large downloaded, nothing in the lake

**Where each input came from:**

  `processing` group, so it was not used for traces.

**Storage.** The derived arrays (cells x 10 repeats x 30 one-second segments) were held in the session's scratch
directory, never in the repo or the lake.

**Not reachable here:** the Marks & Goard deposit (Dryad, CC0-1.0, one 14.5 GB zip). Dryad returns 401 on its API
download and 403 on its public file stream to this cloud session. So the gratings-versus-movie comparison (HW5 RQ1a) is
NOT read here.

## 3. Method

**Response unit.** The mean dF/F of each cell over each 1-second segment (30 movie frames) of each of the 10 Natural
Movie One repeats in a session.

**Matching.** Only cells present in all three sessions of a mouse, by `cell_specimen_id`.

**The readings,** each from the D0 instrument:
- **within-session ceiling:** the population-vector correlation (`pv_correlation`) between odd and even repeats,
  averaged over the 3 sessions;
- **between sessions:** the same correlation across sessions, computed on opposite halves (A-odd vs B-even and A-even
  vs B-odd), so it is directly comparable with the ceiling;
- **single-cell tuning:** the median of `tuning_correlation` on full-session profiles;
- **population geometry:** the correlation of the two sessions' 30 x 30 segment-similarity (RSA) matrices.

**Behavioural control.**
- Each cell's 300 samples are fitted as a segment effect plus z-scored running speed (and pupil area), by least
  squares. The behaviour part is removed and the readings repeat.
- Samples without pupil are dropped from the run+pupil fit only.
- Missing pupil per session: 13-93% of segments (the median session about 40%).

## 5. Reading against the published directions (descriptive, DEV only)

1. **Drift exists** (Deitch et al. 2021; Marks & Goard 2021). The between-session correlation is below the
   within-session ceiling in 11 of 12 pairs; Rorb AB is tied (0.461 vs 0.459). In the two Cux2 mice the gap is large:
   a ceiling of 0.77-0.79 against 0.19-0.58 between sessions.
2. **Geometry is preserved better than single cells** (Deitch et al. 2021). The RSA correlation exceeds the median
   single-cell tuning correlation in 10 of 12 pairs.
   - The two exceptions are both in container 511510855, and both are pairs with its session C: 4 and 6 days apart,
     the longest gaps in this set, with geometry 0.034 and 0.157.
   - Session C is internally reliable (split-half population correlation 0.839, split-half RSA 0.777), and its movie
     timing matches the other sessions. So this is not an extraction fault.
   - It is a one-mouse lead about elapsed time, not a finding.
3. **Elapsed time.** In 511510855 (2, 4 and 6 days) the between-session correlation falls monotonically:
   0.447 -> 0.296 -> 0.185. The other three mice span only 1-2 days, which is too little range to read.
4. **Behaviour explains almost none of it here.** Removing running (and pupil) changes the between-session correlation by at most 0.012 and the geometry by at most 0.045.
   - Sadeh & Clopath (2022) report that behaviour explains a substantial share of apparent drift in these data. **This
     DEV reading does not reproduce that.**
   - It may be the method: a linear removal at 1-second resolution, with up to 93% of pupil samples missing in a
     session. Or it may be these four mice.
   - It is the first question for the pre-registration (section 6). It is not a refutation.

**Per MAP D0's rule, the instrument is NOT blind on the drift direction.** It reproduces "drift exists" and, in 3 of 4
mice, "geometry is preserved better than single cells". Whether that holds on the sealed set is the held-out read's
question.

## 6. What the pre-registration must fix before the held-out read

1. **The verdict rules and their paired statistic.** 48 mice exceeds `paired_contrast`'s n <= 40, which is MAP owner
   decision 4.
2. **The behavioural model.** The time resolution (1 s or frame-level), the pupil-missingness rule, and a planted
   behaviour-driven fake drift that the control must remove: its constructed red.
3. **Elapsed time as a predictor.** The Allen sessions span 1-6 days. A reading over longer spans needs the Marks &
   Goard deposit, which needs a browser download or a Dryad token from the owner.
4. **Aims 2-3** (null space, decoder rescue). With 30 segment classes and over 100 matched cells, the capacity guard
   refuses a per-segment decoder on 150 training trials. The class grouping or the cell subset must be pre-registered,
   never tuned on DEV.

**The range reader** (stdlib only):

```python
"""A read-only, seekable file object over HTTP Range requests (stdlib only), for h5py's fileobj driver.
Fetches 1 MiB blocks on demand and caches them, so opening a 40 GB NWB reads only the bytes it touches."""
import io
import urllib.request
from collections import OrderedDict

BLOCK = 1 << 20


def resolve(url):
    """Follow redirects once (DANDI download -> S3) and return the final URL and total size."""
    req = urllib.request.Request(url, headers={"Range": "bytes=0-0"})
    with urllib.request.urlopen(req, timeout=120) as r:
        return r.geturl(), int(r.headers["Content-Range"].rsplit("/", 1)[1])


class RangeFile(io.RawIOBase):
    def __init__(self, url, cache_blocks=512):
        self.url, self.size = resolve(url)
        self.pos = 0
        self.cache = OrderedDict()
        self.cache_blocks = cache_blocks
        self.fetched = 0

    def readable(self):
        return True

    def seekable(self):
        return True

    def tell(self):
        return self.pos

    def seek(self, off, whence=0):
        self.pos = off if whence == 0 else self.pos + off if whence == 1 else self.size + off
        return self.pos

    def _block(self, i):
        if i in self.cache:
            self.cache.move_to_end(i)
            return self.cache[i]
        lo, hi = i * BLOCK, min(self.size, (i + 1) * BLOCK) - 1
        req = urllib.request.Request(self.url, headers={"Range": f"bytes={lo}-{hi}"})
        for attempt in range(4):
            try:
                with urllib.request.urlopen(req, timeout=120) as r:
                    data = r.read()
                break
            except Exception:
                if attempt == 3:
                    raise
        self.fetched += len(data)
        self.cache[i] = data
        if len(self.cache) > self.cache_blocks:
            self.cache.popitem(last=False)
        return data

    def readinto(self, b):
        n = min(len(b), max(0, self.size - self.pos))
        out, got = memoryview(b), 0
        while got < n:
            i, off = divmod(self.pos + got, BLOCK)
            blk = self._block(i)
            take = min(n - got, len(blk) - off)
            out[got : got + take] = blk[off : off + take]
            got += take
        self.pos += n
        return n
```

**The per-session extraction.** Run from the folder holding the three blocks, with the session's ophys experiment id,
its eye-tracking key from the pin, and an output path:

```python
"""DEV extraction: per session, Natural Movie One responses as (cells, repeats, segments) of mean dF/F, plus running
speed and pupil area on the same grid. Range-reads only the slices needed; writes one small npz per session."""
import json
import sys
import urllib.request

import h5py
import numpy as np

from rangefile import RangeFile

SEG = 30  # movie frames per segment: 30 frames = 1 s at 30 Hz, so 30 segments per 900-frame repeat


def nwb_link(exp_id):
    q = ("https://api.brain-map.org/api/v2/data/query.json?criteria=model::WellKnownFile,rma::criteria,"
         f"well_known_file_type[id%24eq514173063],[attachable_id%24eq{exp_id}]")
    w = json.load(urllib.request.urlopen(q, timeout=120))["msg"]
    assert len(w) == 1, (exp_id, w)
    return "https://api.brain-map.org" + w[0]["download_link"]


def windows(stim_ts, stim_frames):
    """(repeat, segment) -> (t_start, t_end) of each 30-frame movie segment."""
    starts = np.flatnonzero(stim_frames == 0)
    out = []
    for s in starts:
        rep = []
        for k in range(900 // SEG):
            i0, i1 = s + k * SEG, s + (k + 1) * SEG - 1
            rep.append((stim_ts[i0], stim_ts[i1] + 1 / 30))
        out.append(rep)
    return np.array(out)  # (repeats, segments, 2)


def bin_mean(t, x, win):
    """Mean of samples x at times t inside each window; x may be (n, T) or (T,)."""
    lo = np.searchsorted(t, win[..., 0])
    hi = np.searchsorted(t, win[..., 1])
    if x.ndim == 1:
        return np.array([[np.nanmean(x[a:b]) if b > a else np.nan for a, b in zip(r0, r1)] for r0, r1 in zip(lo, hi)])
    return np.stack([np.stack([x[:, a:b].mean(axis=1) for a, b in zip(r0, r1)], axis=1) for r0, r1 in zip(lo, hi)], axis=1)


def extract(exp_id, eye_key, out):
    f = RangeFile(nwb_link(exp_id))
    h = h5py.File(f, "r")
    p = "processing/brain_observatory_pipeline/"
    st = h["stimulus/presentation/natural_movie_one_stimulus"]
    stim_ts, stim_fr = st["timestamps"][:], st["data"][:]
    win = windows(stim_ts, stim_fr)
    t2p = h[p + "DfOverF/imaging_plane_1/timestamps"][:]
    i0 = max(0, int(np.searchsorted(t2p, win.min())) - 2)
    i1 = int(np.searchsorted(t2p, win.max())) + 2
    dff = h[p + "DfOverF/imaging_plane_1/data"][:, i0:i1]
    resp = bin_mean(t2p[i0:i1], dff, win)  # (cells, repeats, segments)
    cells = h[p + "ImageSegmentation/cell_specimen_ids"][:]
    rs_t = h[p + "BehavioralTimeSeries/running_speed/timestamps"][:]
    rs = h[p + "BehavioralTimeSeries/running_speed/data"][:]
    run = bin_mean(rs_t, rs, win)
    meta = {k: h["general/" + k][()].decode() for k in ("session_type", "targeted_structure", "experiment_container_id")}
    nwb_mb = f.fetched / 1e6
    e = RangeFile("https://allen-brain-observatory.s3.amazonaws.com/" + eye_key)
    eh = h5py.File(e, "r")
    et = eh["synced_frame_timestamps/values"][:]
    pa = eh["new_pupil_areas/values"][:]
    pupil = bin_mean(et, pa, win)
    np.savez_compressed(out, resp=resp.astype(np.float32), cells=cells, run=run, pupil=pupil, win=win, **meta)
    return resp.shape, meta, round(nwb_mb, 1), round(e.fetched / 1e6, 1), float(np.mean(np.isnan(pupil)))


if __name__ == "__main__":
    exp_id, eye_key, out = sys.argv[1], sys.argv[2], sys.argv[3]
    print(exp_id, *extract(exp_id, eye_key, out))
```

**The DEV reading.** Needs `split.json` (the pin's dev block) and the per-session npz files in `dev/`:

```python
"""DEV reading (4 mice, descriptive only): does the D0 instrument reproduce the published directions on Allen V1
Natural Movie One, with and without the behavioural control? Uses snn_data_lake.instruments.representational_drift."""
import json
import sys
from datetime import date
from itertools import combinations

import numpy as np

from snn_data_lake.instruments import representational_drift as rd

split = json.load(open("split.json"))


def load(exp_id):
    z = np.load(f"dev/{exp_id}.npz")
    return {k: z[k] for k in z.files}


def residualize(resp, run, pupil, use_pupil):
    """Remove each cell's linear dependence on running (and pupil) across repeat x segment samples, keeping the
    segment means: fit resp = segment effect + b * behaviour by least squares, return the segment-effect part."""
    c, r, s = resp.shape
    seg = np.tile(np.eye(s), (r, 1))  # (r*s, s) one-hot segment design
    beh = [run.reshape(-1)]
    if use_pupil:
        beh.append(pupil.reshape(-1))
    b = np.column_stack(beh)
    ok = np.all(np.isfinite(b), axis=1)
    b = (b - np.nanmean(b[ok], axis=0)) / (np.nanstd(b[ok], axis=0) + 1e-12)
    x = np.hstack([seg, b])[ok]
    y = resp.reshape(c, -1)[:, ok].T  # (samples, cells)
    coef, *_ = np.linalg.lstsq(x, y, rcond=None)
    clean = resp.copy()
    full_b = np.where(ok[:, None], b, 0.0)
    clean = (resp.reshape(c, -1).T - full_b @ coef[s:]).T.reshape(c, r, s)
    return clean, int(ok.sum())


def rsa(profile):
    """Segment x segment correlation of population vectors (the representational geometry)."""
    return np.corrcoef(profile.T)


def upper(m):
    i, j = np.triu_indices(m.shape[0], 1)
    return m[i, j]


rows = []
for c in split["dev"]:
    sess = {s[0][-1] if s[0] != "three_session_C2" else "C": (s[1], date.fromisoformat(s[2])) for s in c["sessions"]}
    data = {k: load(v[0]) for k, v in sess.items()}
    common = set(data["A"]["cells"])
    for k in "BC":
        common &= set(data[k]["cells"])
    common = sorted(common)
    for mode in ("raw", "run", "run+pupil"):
        prof, half = {}, {}
        nbeh = {}
        for k, d in data.items():
            idx = [list(d["cells"]).index(x) for x in common]
            resp = d["resp"][idx]
            if mode != "raw":
                resp, nbeh[k] = residualize(resp, d["run"], d["pupil"], mode == "run+pupil")
            prof[k] = resp.mean(axis=1)  # (cells, segments)
            half[k] = (resp[:, 0::2].mean(axis=1), resp[:, 1::2].mean(axis=1))
        within = np.mean([rd.pv_correlation(*half[k]) for k in "ABC"])
        for a, b in combinations("ABC", 2):
            days = abs((sess[b][1] - sess[a][1]).days)
            between_half = np.mean([rd.pv_correlation(half[a][0], half[b][1]), rd.pv_correlation(half[a][1], half[b][0])])
            tun = rd.tuning_correlation(prof[a], prof[b])
            geo = float(np.corrcoef(upper(rsa(prof[a])), upper(rsa(prof[b])))[0, 1])
            rows.append({"container": c["container"], "cre": c["cre"], "mode": mode, "pair": a + b, "days": days,
                         "cells": len(common), "within_half_pv": round(float(within), 4),
                         "between_half_pv": round(float(between_half), 4),
                         "pv_full": round(rd.pv_correlation(prof[a], prof[b]), 4),
                         "tuning_median": round(float(np.nanmedian(tun)), 4), "rsa_geometry": round(geo, 4),
                         "beh_samples": {k: nbeh.get(k) for k in "ABC"} if mode != "raw" else None})

json.dump(rows, open("dev_reading.json", "w"), indent=1)
for mode in ("raw", "run", "run+pupil"):
    print(f"== {mode}")
    print("container  cre         pair days cells  within  between  pv_full  tuning_med  rsa_geo")
    for r in rows:
        if r["mode"] == mode:
            print(f"{r['container']} {r['cre'][:10]:10s} {r['pair']}   {r['days']:>2}  {r['cells']:>4}  {r['within_half_pv']:.3f}  "
                  f"{r['between_half_pv']:.3f}    {r['pv_full']:.3f}   {r['tuning_median']:.3f}      {r['rsa_geometry']:.3f}")
```
