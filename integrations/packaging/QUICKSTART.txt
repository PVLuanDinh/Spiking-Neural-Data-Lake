SPIKING NEURAL DATA LAKE - QUICKSTART
=====================================

WHAT IS THIS?
A zero-dependency neuromorphic robot-arm control panel + spiking data lakehouse.
Desktop app for Windows 64-bit.  No Python install required.

HOW TO RUN
1. Unzip this archive to a folder.
2. Double-click snn-ui.exe to launch.

THE FIVE TABS
  Arm Control      Live 2-link arm (simulated by default). Every button is safety-gated:
                   collision, EMERGENCY_STOP, allow-list. Connect serial (COM) to drive
                   a REAL arm -- calibration-gated, no bypass.

  Live Recognition Replay the bundled sample gesture captures as live arm commands
                   (step or auto-play); Open CSV... to load your OWN capture.

  Lake Browser     Load the demo store, Open your OWN .spk, or use Import data... (a wizard
                   for spike-event OR dense sensor CSV -> a queryable store); run queries.

  NL Command       Type an English command ("close the effector", "go home",
                   "STOP", "read telemetry channel 7 window 1000"). It maps to a
                   safe allow-listed arm action (driven through the same gated
                   Arm Control path) or a lake query, or is rejected. Zero-dep
                   keyword backend by default.

  Diagnostics      Run the ENTIRE core from inside the app: every core module's
                   self-check, PASS/FAIL live (a build / self-test diagnostic). The
                   whole core is bundled in this .exe. Headless: snn-ui.exe --run-core

SMOKE TEST (No Display)
  If you have no GUI display, verify the app works:
    snn-ui.exe --smoke
  Should print a self-check line and exit with code 0.

SAFETY NOTES
  The arm is SIMULATED by default (no hardware connected).
  All motor commands pass through collision detection and EMERGENCY_STOP.
  The allow-list gate restricts which commands can be sent.
