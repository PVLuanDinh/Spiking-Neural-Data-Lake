# До первого task-run: уточнение обвязки

При чтении DeltaAdaptor обнаружено: общий respond вызывает offline `_settle()` до
первого learn, а delta ничего offline не обучает. Для исходного/frozen beta используем
его готовый чистый `_answer(x)` во всех delta arms. Математика ответа та же, исходники
не меняются, `_ready` не меняется от оценки. Это нужно для честного before/no-tune.

Снимки delta перечисляют beta и все изменяемые поля adaptor/rule явно; R-STDP
использует проверку `_snapshot` из этапа 03 с hydration-полями. Признаки сохраняются
отдельным worker до arms: final-цели ни один обучающий вызов не получает.
