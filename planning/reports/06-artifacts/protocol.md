# 06: локальный диагностический протокол — до task data

2 ноября 2026 года, America/Chicago. Основа c4c10b285f1741aa798d5ee9c5296ae371fabecf.
Это продолжение раскрытого development-пилота, не подтверждающая G6 campaign.
Все результаты, включая отказы, сохраняются; исходники и старые артефакты неизменны.

1. Census: штатный sleep_pruner_census.census_static с его self-check (посаженные
   add/delete reds). Полный Brain не запускать ради census: восприятие отложено,
   исторический CLI допускает собственный G6 seed block. Отделить static достижимость
   от измеренных вызовов выбранного pruner в компонентном опыте.
2. Длительность: копии одного b30 lake этапа 05; seeds 8000–8003 уже раскрыты.
   Replay 0, 1, 2, 5, 10 полных смешанных эпох (32 train строки на эпоху), порядок
   тот же, что в 05. Рост и reservoir заморожены. Отдельный label-shuffle на 10 эпохах.
   Данные dev/final не replay и не источник остановки. Все бюджеты выполнить;
   выбирать лучший по final нельзя. Проверить полное совпадение 0/10 с 05.
3. Стадии: проверить реальный контракт staged_sleep_bout против delta baseline.
   Если нет законного REM/rest consumer, записать NOT EVALUATED и конкретную причину.
   Не изобретать новый plasticity rule и не возвращать retired automatic sleep.
   Сам runner проверить его штатным brain-free self-check; его fixtures не считать
   результатом обучения. Равенство presentations не называть равенством CPU.
4. Pruning: P-LL / LifelongConsolidator._prune_to_budget, штатные _make_tasks,
   dim=36, budget=6, replay=True, epochs=2, прочие defaults. Seeds те же открытые
   8000–8003; у этого нового fixture это exploratory раскрытие, не confirmatory.
   Сначала обучить три задачи с prune=False. Из ТОГО ЖЕ состояния независимо:
   OFF; magnitude ON; штатный random (тот же размер); highest-utility-first
   как саботаж (та же мощность маски). Каждый arm — новый процесс. Рост/обучение
   после развилки выключены; это одна операция выбора после обучения, не сравнение
   многолетних траекторий. При n<=6 честно INERT, бюджет не подгонять.
   Измерять ответы каждой A/B/C, состав/число прототипов, work поиска n_units*dim,
   время самой selection, время classify, число comparisons и размер lake.
   Нет перебора гиперпараметров; random — один заранее заданный RNG, без отбора.
5. Сохранение: append-only named state (0x07), отдельный NORD_HOME на arm.
   Сохранить исходное и принятое состояние; не удалять lake records при pruning.
   P-LL: штатный state_dict/load_state_dict; train streams из lake и rebuild_memory,
   оба RNG состояния и config сохраняются/сверяются. Новый restore получает только
   x, без целей. Длительность: тот же save/load carrier 05, восстановление признаков
   по текстам без целей. Writer завершён перед restore. Проверка hashes и всех ответов.
6. Controls до task data на раскрытом scratch 8900: scorer чувствителен к неверным
   ответам; штатный prune меняет известный набор ровно по рангу, random режет столько
   же; саботаж теряет класс; learn запрещён при оценке; missing/corrupt/stale/profile
   и неверная ширина/маска должны быть обнаружены. Повтор seed 8000 не увеличивает N.

Sample size (P1): четыре ранее раскрытых dev seeds нужны для совместимости с 05,
не для популяционного вывода. Paired SD до опыта неизвестна для pruning; мощность
не заявляется, alpha/статистические KEEP/RETIRE решения не применяются. Все сравнения
описательные. Числа 1/2/5/10 — заранее объявленные точки diagnostic dose curve,
а не рекомендованная длительность. Для будущей campaign нужны измеренная SD,
минимальный эффект, multiplicity, power .8, lawful untouched seeds и sequential plan.
Нулевая SD этих четырёх не считается доказательством отсутствия вариативности.

Критерий узкого результата: воспроизводимые записи всех arms и корректные controls;
отдельный вывод по длительности и pruner; стадии могут остаться не оценены из-за
конкретного несовместимого интерфейса. Успех pruning требует удержания каждой задачи
не хуже OFF и реального сокращения поиска; иначе вывод ограничить наблюдаемой потерей
или неопределённостью. Код не удаляется: underpowered чтение не NULL, P8 10x не лицензирован.
